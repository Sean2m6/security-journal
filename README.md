# Security Journal

Notes and write-ups from me learning cybersecurity through hands-on practice.

This is where I document the boxes I solve on HackTheBox and
TryHackMe, along with lessons from the security lab I run on my own network.
I'm focused on the defensive side of things, so where it makes sense I include
how you'd actually spot or prevent each issue in the real world, not just how
to exploit it.

It's a work in progress and I'm learning as I go, so expect it to grow over time.

## Cars and ECUs

I'm a car guy, and part of what pulls me into this is that a modern car is
really just a bunch of small computers talking to each other on a network. That
overlaps with the security side more than I expected.

I scan, explore, and modify the ECU and module data on my own car. Using FORscan
I went into the As-Built data and changed the values myself to turn on cruise
control, keyless entry, and remote trunk release, and to change when the cabin
lights come on. Credit to FORscan for giving me the idea to learn how all of it
works.

It comes back to the same thing as the rest of this repo. I like knowing how
stuff actually works, whether that's a car module or a box on HackTheBox.

## What's in here

## A few ground rules I stick to

- No flags or spoilers for active HackTheBox machines. That's against their
  rules, so only retired and Starting Point boxes get written up here.
- I don't post actual flag values. The whole point is to earn them.
- Everything here is practice on platforms built for it, or on my own
  equipment that I own and have permission to test.
